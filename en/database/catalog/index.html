Revision 0005_results adds the supporting unique key (id, material_id) to material_properties so that results can verify that the referenced property belongs to the quantified material.

Revision 0006_integrity adds non-NaN checks to value, min_value, max_value in material_properties, positivity when the type is density, nonempty classification system domains and domain compatibility in assignments. It prevents changes to the semantic identity of the domain, version system, node version, type code/unit and property type. It checks cycles in nodes, materials and property successions. See integrity.

Batch imports

The reference adapter groups source records and resolves reference, material, alias and classification keys using queries bounded to relevant identities. Classifications are resolved by level: each parent must exist before creating its children. For densities, the latest adapter property per material is queried; properties from other sources remain unchanged. Changes are written in batches without changing identity or versioning rules.

Identifiers returned by inserts are correlated with input rows through ordered RETURNING; they are not assumed to be consecutive. Provenance of each relationship and the first occurrence of repeated keys are retained. Integrity checks and a single transaction per import are maintained.

See the catalog import guide for format, identity and use.

ES/EN/FR editorial labels (0009_localization, 0011_french_labels)

Table Entity key FK target
catalog.material_labels material_id catalog.materials.id
catalog.classification_system_labels system_id catalog.classification_systems.id
catalog.classification_node_labels node_id catalog.classification_nodes.id
catalog.property_type_labels property_type_id catalog.property_types.id
Field Type Constraint
Entity identifier (see preceding table) BIGINT Composite PK, FK RESTRICT
language TEXT Composite PK; es, en or fr
source_text TEXT NOT NULL, nonempty
label TEXT NOT NULL, nonempty
origin TEXT NOT NULL, nonempty
note TEXT Optional
created_at TIMESTAMP WITH TIME ZONE NOT NULL, DEFAULT now()

Each label table uses the same structure. Its composite primary key prevents more than one label per entity and language. The foreign key restricts deletion of the original entity. source_text preserves the translated original; if it no longer matches the entity, presentation queries return NULL and the viewer retains the original. origin records editorial provenance; note can record ambiguity and limitations. These are neither scientific calculation inputs nor material equivalences. The loader does not overwrite differing labels; later revisions must be resolved explicitly.
